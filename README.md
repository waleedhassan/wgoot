# وَقُوتُ الصَّلاة — wgoot

تطبيق مواقيت الصلاة والتاريخ الهجري وتنبيه الأذان، بلغة تصميم تطبيقَي
«الأربعون النووية» و«حصن المسلم».

الاسم مأخوذ من تسمية الإمام مالك بن أنس رحمه الله في «الموطأ»، فقد افتتح كتابه
بـ«كتاب وُقُوت الصلاة»، و«الوُقُوت» جمع وقت.

- **معرّف الحزمة / Bundle ID:** `apps.waleed.sunnah.wgoot`
- **المنصّات:** Android · iOS · Web

## المزايا

- مواقيت الصلوات الخمس مع الشروق، محسوبة فلكياً على الجهاز **بدون إنترنت**.
- اختيار المدينة من قائمة تضم أكثر من ١٨٠ مدينة مع بحث عربي يتجاهل التشكيل
  ويوحّد الهمزات.
- تعيين طريقة الحساب **تلقائياً** حسب دولة المدينة (أم القرى، المصرية، رابطة
  العالم الإسلامي، كراتشي، دبي، الكويت، قطر، ديانت، سنغافورة، ISNA…)، مع
  إمكانية اختيارها يدوياً.
- مذهب حساب العصر (الجمهور / الحنفي) وقاعدة خطوط العرض العالية.
- **تعديل يدوي** لكل وقت من −٦٠ إلى +٦٠ دقيقة، ينعكس على الجدول والتنبيهات معاً.
- تنبيه عند دخول الوقت مع تذكير اختياري قبله (٥–٣٠ دقيقة)، وكتم أي صلاة على حدة.
- التاريخ الهجري (أم القرى) مع تعديل ±٣ أيام.
- جدول مواقيت الشهر كاملاً مع إبراز اليوم الحالي وأيام الجمعة.
- مظهر فاتح/داكن، ونظام ١٢/٢٤ ساعة، وأرقام هندية عربية، وواجهة RTL بالكامل.

### حساب المواقيت عبر المناطق الزمنية

تُحسب المواقيت بـ `PrayerTimes.utc` فتخرج بتوقيت UTC، ثم تُحوَّل إلى المنطقة
الزمنية الخاصة بالمدينة عبر `tz.TZDateTime.from(...)`. لذلك تظهر مواقيت أي مدينة
صحيحةً بتوقيتها المحلي بغضّ النظر عن توقيت الجهاز.

## صوت الأذان

يجدول التطبيق التنبيهات على قناة إشعارات بخصائص **المنبّه**
(`AudioAttributesUsage.alarm`)، ويستخدم افتراضياً صوت التنبيه الافتراضي في
النظام لأن التطبيق لا يشحن ملفاً صوتياً للأذان.

لتفعيل الأذان الحقيقي:

1. ضع ملفاً صوتياً باسم `adhan.mp3` في
   `android/app/src/main/res/raw/adhan.mp3`.
2. غيّر الثابت في
   [`lib/src/notifications/notification_service.dart`](lib/src/notifications/notification_service.dart):

   ```dart
   const String? kAdhanRawResource = 'adhan';
   ```

3. أزل التطبيق وأعد تثبيته (خصائص قناة الإشعارات على أندرويد لا تتغيّر بعد
   إنشائها).

## الجدولة والأذونات

- يجدول التطبيق **الأيام العشرة القادمة** ويعيد الجدولة عند كل فتح للتطبيق أو
  عند تغيير المدينة/الإعدادات.
- أذونات أندرويد: `POST_NOTIFICATIONS` · `SCHEDULE_EXACT_ALARM` ·
  `RECEIVE_BOOT_COMPLETED` · `VIBRATE`، مع مستقبِل إعادة الجدولة بعد إقلاع
  الجهاز أو تحديث التطبيق.
- إن رفض النظام المنبّهات الدقيقة يتراجع المجدول تلقائياً إلى جدولة غير دقيقة
  بدل أن يفشل.

## النشر على Google Play

كل ما يطلبه المتجر — نصوص الصفحة بالعربية والإنجليزية، وسياسة الخصوصية،
وإجابات نموذج «أمان البيانات» وتصنيف المحتوى — جاهز في
[`store/play/`](store/play/README.md)، والخطوات بالترتيب في
[`store/play/release-process.md`](store/play/release-process.md).

أنشئ مفتاح التوقيع مرة واحدة:

```bash
python store/tool/release.py keystore
```

ثم لكل إصدار، أمر واحد يفحص ويبني ويوقّع ويجمع كل ما يُرفع:

```bash
python store/tool/release.py --bump build
```

تفصيل الأداة في [`store/tool/README.md`](store/tool/README.md)، وهي صالحة لأي
تطبيق Flutter لا لهذا التطبيق وحده.
